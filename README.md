# phreshphish
PhreshPhish is the largest, highest-quality phishing dataset to date.

Dataset is available here: https://huggingface.co/datasets/phreshphish-anon/phreshphish

## Contents
- `baselines` Training and evaluation code for the benchmark models.
- `benchmark` Jupyter notebooks for creating the benchmarks.
- `dataset` Cleaning, EDA, PII removal, scraping, and train-test split code.
